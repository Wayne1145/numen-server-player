# 投影蓝图 → Numen 服务端施工设计

## 结论

不在服务器安装 Litematica/投影模组。采用“可选客户端桥接模组 + Numen 服务端协议”的双端设计：客户端只读取玩家当前加载并启用的投影，把**归一化蓝图**安全发送给服务器；服务器独立校验、保存计划，再交给真实 `ServerPlayer` 通过现有 `build` 分批施工。

## 组件

1. **客户端可选桥接模组（Forge 1.20.1）**
   - 对社区 Forge 移植版投影模组使用 `compileOnly`/反射适配，未安装时不影响进服。
   - 读取当前选中的 placement、原点、旋转/镜像、启用区域及方块状态。
   - 不上传任意本地路径；只上传已加载投影的归一化方块清单。
2. **Numen 服务端蓝图入口**
   - 自有可选网络通道只在客户端与服务端双方安装桥接时注册；普通客户端仍可无模组加入。
   - 分片上传：`manifest → chunks → finalize`，每片限长、总格数/体积/维度有硬上限。
   - 绑定玩家、同伴、维度、锚点、一次性 nonce 与过期时间；服务端重新计算 SHA-256。
3. **施工计划器**
   - 将客户端相对坐标和方块状态转换为绝对世界坐标。
   - 先做预检：权限/边界、受保护方块、未知 namespace、材料缺口、已正确格、需清除格、方块实体。
   - 按依赖与层高排序，每批 ≤512 格调用现有 `build`；每批后感知核验并保留 checkpoint。

## 数据边界

- 支持：普通方块、完整 block state、旋转/镜像后的方向/轴/半砖/楼梯等。
- 首版不自动复制：箱子物品、告示牌文本、命令方块、刷怪笼、实体、流体动态、模组方块实体 NBT。
- 方块实体默认只放空壳，并在预检报告中明确列出；危险 NBT 永不由客户端直接写入。
- 材料必须来自假人真实背包/允许容器，缺料时暂停并返回人类化清单，不凭空生成。

## 安全与恢复

- 默认 `replace_existing=false`；清除/覆盖单独授权。
- 服务端保存蓝图 ID、哈希、提交者、锚点、批次和已完成位图；死亡/重启后可续建。
- 每批记录变更前状态，允许在限定窗口内回滚本批；容器与受保护块不自动回滚覆盖。
- 区块未加载时由假人真实移动加载，不强制常驻加载整张大图。

## 阶段验收

1. **设计级（当前）**：完成协议、边界、威胁模型与批处理规则。
2. **最小桥接**：客户端读取 5×5×5 投影，服务器预检报告坐标/材料/哈希一致，不施工。
3. **小型施工**：100 格内普通方块，旋转/镜像正确，逐格核验 100%。
4. **中型续建**：>512 格跨批次，重启后续建，无重复消耗/漏放。
5. **兼容性**：没装桥接或投影模组的客户端正常进服；服务端始终不需要投影模组。

当前需求优先级不高，因此先停在设计级；底层 `build` 已具备落地所需的绝对坐标、方块状态、分层和 512 格批次能力。
