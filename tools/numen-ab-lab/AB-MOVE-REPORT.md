## 已证实原因

1. **长期租约设计不适合慢模型**：单轮 LLM 约 40–67 秒，120 秒租约会在多轮思考时过期。修复为每个写动作临时 `acquire → invoke → release`。
2. **`idle` 缺少任务终态**：模型只能看到派发回执，再主动读取身体状态；无法直接知道 done/failed/timeout。
3. **缺少导航停止语义会诱发重复动作**：Numen-v1 将离目标 0.57 格视为未完成，再次 `goto`。Numen-v2 明确“水平距离 ≤1.5 格即到达，验证后立即 final”，重复动作消失。
4. **专业 Prompt 不是越强硬越好**：`Act until done` 若没有工具完成条件，会降低而不是提高表现。
